# AI 專屬工作技能 (Skills SOP)

## 技能名稱：匯入 Google 文件並轉換為 Markdown

### 觸發條件
當使用者提供一串 Google Docs 的公開分享連結時。

### 執行流程
1. **設定工作目錄**
   - 確保工作目錄為專案下的 `course` 資料夾。

2. **執行轉換工具**
   - 執行命令：`python import_gdoc.py <Google文件連結>`。
   - 工具運作原理：`import_gdoc.py` 會向 Google 請求該文件的 HTML 匯出版本，並自動過濾掉冗長的 Google 追蹤重新導向網址（`google.com/url?q=`），還原成乾淨的原始超連結。

3. **依賴套件處理 (自動)**
   - 轉換過程依賴 `beautifulsoup4`（負責解析複雜的 HTML 樹狀結構）與 `markdownify`（負責將網頁標籤轉換為標準 Markdown 語法）。
   - 若環境中缺失這兩個套件，需確保透過 `pip` 補齊安裝。

4. **驗證與存檔**
   - 轉換成功後，程式會自動以文件標題命名，並儲存為 `.md` 檔案。
   - 確保該檔案正確儲存在 `course` 資料夾內。

5. **後續回報**
   - 向使用者回報產生的完整檔名與路徑。
   - 主動詢問使用者是否需要執行「發布新文章上線」的技能。
